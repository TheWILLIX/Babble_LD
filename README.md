# Babbles HDRP
## Règles de vie :
- Ne pas bosser sur les mêmes maps
  - Pour tout prototypage, chacun sur sa propre scène
- Mentionner si doit bosser sur la map principale
- Ranger les objets des scènes communes dans des objets vides
## Nomenclature :
- Code
  - Quand on nomme un résultat:
    - r => Court terme
    - res => Alternative à r
    - result => la valeur retournée de la méthode/fonction
  - Réduire les var pour les types non-simples, faire des déclarations de type instead
  - Nommage des variables & fonctions => nom au plus proche de sa fonction
  - Mettre des régions à partir du moment où y'a beaucoup de méthodes
- Unity
  - Nommage unity => type_(catégorie si nécessaire_)nom
  - Si un type n'avait pas déjà de nommenclature, dès le moment elle a été choisie, mettre tout le monde au courant
## Format de rangement de dossiers :
Dossiers => Catégorie (script/matériaux) => Fonction (caméra/mouvements/actions)
